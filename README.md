# Expense Tracker (Трекер расходов)

**Автор:** Васина Анастасия

## Описание
Графическое приложение для учёта личных расходов. Позволяет добавлять расходы с указанием суммы, категории и даты, фильтровать записи по категории и дате, подсчитывать сумму расходов за выбранный период. Данные сохраняются в файл `expenses.json` и автоматически загружаются при запуске.

## Требования
- Python 3.6+
- Стандартные библиотеки: tkinter, json, os, datetime (входят в поставку Python)
