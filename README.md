# Expense Tracker (Трекер расходов)

**Автор:** Васина Анастасия

## Описание
Графическое приложение для учёта личных расходов. Позволяет добавлять расходы с указанием суммы, категории и даты, фильтровать записи по категории и дате, подсчитывать сумму расходов за выбранный период. Данные сохраняются в файл `expenses.json` и автоматически загружаются при запуске.

## Примеры использования

**Корректный ввод (позитивный тест):**  
Сумма = 250.50, Категория = "Еда", Дата = 2025-03-15.  
После нажатия "Добавить расход" запись появляется в таблице.

**Деление на ноль (негативный тест):**  
Пользователь ввёл число 0 или отрицательное значение. Программа выводит сообщение: "Сумма должна быть положительным числом".

**Пустая строка (граничный тест):**  
Пользователь не ввёл сумму. Программа выводит сообщение: "Сумма должна быть положительным числом".
